# Заметка для исследования FreeToken-MLX на две страницы

В этом каталоге находится черновик заявки на NeurIPS 2026 ML for Systems Workshop, краткая исследовательская заметка в формате Markdown и манифест доказательств.

- `main.tex`: каноническая рукопись воркшопа на три содержательные страницы в официальном формате NeurIPS 2026 (`sglblindworkshop`) с анонимизированными метаданными автора; список литературы следует за основным текстом.
- `references.bib`: источники, используемые в рукописи воркшопа.
- `SUBMISSION_READINESS.md`: проверенные требования площадки, рубрика рецензирования и оставшаяся высокоприоритетная работа.
- `SHORT_PAPER.md`: компактный проектный брифинг в стиле двух страниц.
- `data/measurements.json`: машиночитаемые измерения и ограничения области применения.
- `bench_memory_curve.py`: скрипт проверки бюджета кэша с защитой безопасности и запуском свежих процессов.
- `plot_memory_curve.py`: детерминированный рендерер векторных рисунков.
- `data/memory_curve_cooled_runs.json`: все 15 прогонов, использованных на Рисунке 1.
- `data/memory_curve_summary.json`: производные медианы, диапазоны, пики и промахи.
- `data/memory_curve_sustained_load_runs.json`: сохраненный отклоненный протокол; длительное выполнение показало большой дрейф по времени и не используется для утверждений в статье.
- `figures/memory_throughput_curve.pdf`: векторный источник для Рисунка 1.
- `../output/pdf/freetoken_mlx_ml4sys2026.pdf`: отрендеренный черновик заявки.

Сборка выполняется с помощью Tectonic; скрипт загружает официальный стиль NeurIPS 2026, связанный с воркшопом, во временный каталог и не встраивает и не изменяет его:

```bash
bash paper/build.sh
```

Воспроизведите замеры памяти, сохраняя 3.2GB системного резерва:

```bash
.venv/bin/python paper/bench_memory_curve.py \
  --model ./Qwen1.5-MoE-A2.7B-BF16-Q4Experts \
  --budgets-gb 0.25 0.50 0.75 1.00 1.25 \
  --repeats 3 --max-tokens 64 \
  --initial-cooldown-seconds 120 --cooldown-seconds 45
```

Запуск прерывается перед началом точки, если macOS сообщает о менее чем 35% свободной памяти. На Рисунке 1 показаны все наблюдения пропускной способности и медиана; его утверждение намеренно ограничено, поскольку диапазоны трех прогонов пересекаются.

Черновик намеренно представлен как предварительное исследование одной системы. Перед подачей расширьте оценку качества за пределы включенного 135-токенового прокси.
